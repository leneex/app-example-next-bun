# Next.js на Bun

Пример приложения [Next.js](https://nextjs.org/) на [Bun](https://bun.sh/).

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/out` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack видит `bun.lock` и
собирает проект через Bun. В `next.config.mjs` включён статический экспорт (`output: "export"`):
Next.js собирает отдельную HTML-страницу на каждый адрес и кладёт их в `out`, поэтому SPA не
нужен — несуществующий адрес отвечает 404.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
bun install

# запуск в режиме разработки
bun run dev

# сборка для продакшн
bun run build
```
